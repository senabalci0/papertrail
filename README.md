#  Papertrail

**A personal bookshelf for readers who love collecting, organizing, and discovering books.**

Papertrail is a bookshelf web application inspired by the joy of building a personal library. It allows readers to create their own colorful digital bookshelf, track their reading progress, and explore books through ratings and reviews.

##  Features

- **Personal Bookshelf:** Add books to a visual bookshelf with different spine colors.
- **Reading Tracker:** Organize books into *Want to Read*, *Currently Reading*, and *Finished* categories.
- **Book Details:** View book information by selecting a book on the shelf.
- **Search & Filter:** Find books and filter your collection by reading status.
- **Ratings & Reviews:** Rate books and share reading experiences.
- **Reading Statistics:** Keep track of your personal reading collection.
- **Local Storage:** Save your bookshelf in the browser between visits.

##  Built With

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

##  Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/senabalci0/papertrail.git
   ```

2. Open the project folder:

   ```bash
   cd papertrail
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

##  Project Goal

Papertrail aims to make digital book tracking feel more personal and visual by combining bookshelf customization, reading progress tracking, and book reviews in one place.
